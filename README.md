# Personal Portfolio Website

## Project Description

This is my personal portfolio website, designed and developed to showcase my professional profile, technical skills, education, learning experience, and web development projects.

The portfolio is fully responsive and designed to provide a clean, modern, and user-friendly experience across desktop, tablet, and mobile devices.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Git & GitHub
- Vercel

## Features

- Responsive and mobile-friendly design
- Professional Home / Hero section
- About Me section
- Technical Skills section
- Dynamic skills rendering using JavaScript
- Education section
- Learning Experience section
- Dynamic project listing
- Project categories
- Project details using Bootstrap Modal
- Dynamic project information from `data.js`
- Project GitHub links
- Project live demo links
- Contact section
- Contact form with JavaScript validation
- Responsive mobile navigation
- Interactive UI elements

## Projects

The portfolio showcases my web development projects, including:

- **Azure Resort** — Resort website
- **NovaTech** — Technology website
- **Creative Technology** — Creative technology website

Each project includes its description, features, technologies used, GitHub repository, and live demo where available.

## JavaScript Structure

The portfolio uses separate JavaScript files to keep the code organized and reusable:

- `data.js` — Stores portfolio data such as skills, education, experience, and projects.
- `portfolio.js` — Handles portfolio and home page functionality.
- `about.js` — Handles About, Education, and Experience functionality.
- `project.js` — Handles project listing and project details modal.
- `contact.js` — Handles contact-related functionality and form validation.

## How to Run the Project

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.

No additional installation or dependencies are required because Bootstrap and other external resources are loaded through CDN links.
